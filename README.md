# TrustX Pro — marketing site

Public site for **https://trustxpro.in**

## Local (XAMPP)

Open: `http://localhost/trustxpro/`

## Pages

| Path | File |
|------|------|
| `/` | `index.html` |
| `/terms` or `/terms.html` | Terms & Conditions |
| `/privacy` or `/privacy.html` | Privacy Policy |

## Deploy

Point the `trustxpro.in` document root to this folder (or sync these files to the host).

Update contact emails (`hello@`, `legal@`, `privacy@`) and legal entity details with your counsel before go-live.
